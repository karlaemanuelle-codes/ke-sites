# Karla Emanuelle - site e CRM MVP

Primeira versão funcional, mobile-first e estática para testes.

- Site público, formulário e WhatsApp.
- CRM local com funil, vendas, pós-venda e avaliações moderadas.
- Configurações editáveis sem credenciais fictícias.

## Limitação do MVP

O CRM usa localStorage: dados apenas no navegador usado, sem sincronização, login ou banco persistente. Não inserir dados sensíveis durante o teste público.
